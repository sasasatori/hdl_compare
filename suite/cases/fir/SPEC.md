# CASE: fir — 16 抽头定点 FIR 滤波器

- 顶层模块名：`fir16`
- 难度：★★★☆
- 考察点：乘加数据通路、流水线、定点舍入/饱和、系数可配置、背压

## 1. 功能要求

16 抽头 FIR 滤波器，数据与系数均为 **Q1.15 有符号定点**（16 bit，范围 [-1, 1-2⁻¹⁵]）：

```
y[n] = sat( round( Σ_{k=0..15} h[k] · x[n-k] ) )
```

**位精确数学定义**（测试以此为准，Python 参考模型逐拍比对）：

```python
acc = sum(h[k] * x[n-k] for k in range(16))   # 精确整数乘加, 36 bit 足够
acc_r = (acc + 0x4000)                         # round-half-up (对负数同样是 +0x4000 后算术右移)
y = acc_r >> 15                                # 算术右移
y = max(-32768, min(32767, y))                 # 饱和
```

系数通过写端口加载（16 × 16bit），写入后**下一拍生效**（影响之后接收的样本）。

## 2. 端口

| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `clk` | in | 1 | 时钟，posedge |
| `rst` | in | 1 | 同步高有效复位 |
| `coef_we` | in | 1 | 系数写使能 |
| `coef_addr` | in | 4 | 系数地址 0..15 |
| `coef_data` | in | 16 | 系数值（Q1.15 二进制补码） |
| `in_valid` | in | 1 | 输入样本有效 |
| `in_ready` | out | 1 | 可接收样本 |
| `in_data` | in | 16 | 输入样本（Q1.15 二进制补码） |
| `out_valid` | out | 1 | 输出有效 |
| `out_ready` | in | 1 | 下游就绪 |
| `out_data` | out | 16 | 滤波结果（Q1.15 二进制补码） |

复位状态：`out_valid=0`，`in_ready=1`，系数全部清零，输入历史清零。`out_data` 复位期间任意。

## 3. 时序与协议

- `in_valid && in_ready` 的时钟沿 → 样本进入滤波器；每个被接收的样本最终必须产生**恰好一个**对应输出（保序）。
- **吞吐要求**：`out_ready=1` 持续时，必须能每拍接收 1 个样本（稳定后无气泡）。允许流水线延迟 `LAT`（首个样本到其输出），`LAT ≤ 32` 拍；`LAT` 将在报告中被记录。
- **背压**：`out_ready=0` 时输出保持（`out_valid` 与 `out_data` 在未被接受前不得改变）；内部流水线塞满后 `in_ready` 可拉低，但不得丢样本。
- 系数写入与数据通路并发：测试只会在无数据传输的间隙写系数，但写系数不得毛刺式破坏正在进行的握手。

## 4. 性能要求

- 连续 512 样本满速（`out_ready=1` 恒定）：总拍数 ≤ 512 + LAT；
- 随机背压（`out_ready` 按拍随机 0/1，占空 ~50%）下数据零丢失、零重复。

## 5. 测试点（权重均等）

| 测试 | 内容 |
|---|---|
| `test_impulse` | 单位系数(冲激 h[0]=32767 近似 1.0) → 输出=输入(量化后)；校验延迟计数 |
| `test_known_coefs` | 固定系数组 + 手工输入序列，逐拍比对参考模型 |
| `test_random` | 随机系数 + 200 随机样本（含 ±满幅），位精确比对 |
| `test_saturation` | 全 32767 系数 + 满幅输入 → 正向饱和；全负 → 负向饱和；校验无回绕 |
| `test_backpressure` | 随机 out_ready，比对样本流完整性 |
| `test_throughput` | 512 样本满速计时，校验吞吐约束 |
| `test_coef_reload` | 中途换系数，换后样本用新系数 |
