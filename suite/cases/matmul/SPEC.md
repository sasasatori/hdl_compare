# CASE: matmul — 4×4 脉动矩阵乘法器

- 顶层模块名：`matmul4x4`
- 难度：★★★☆
- 考察点：二维阵列/生成式参数化、累加数据通路、流式协议

## 1. 功能要求

计算 4×4 矩阵乘 `C = A × B`：

- A、B 元素为 **int8**（二进制补码）；
- C 元素为 **int32**（精确累加，无饱和：`C[i][j] = Σ_{k=0..3} A[i][k]·B[k][j]`，最大值 4·128·128 < 2^17，不会溢出 32 位）。

**打包格式**（LSB 为低索引元素）：

- `a_row[i]` 在一个 32bit 拍中：`a_row[7:0]=A[i][0], a_row[15:8]=A[i][1], a_row[23:16]=A[i][2], a_row[31:24]=A[i][3]`；
- `b_row` 同构：`b_row[8*j +: 8] = B[i][j]`（即第 i 行）；
- `c_row` 128bit：`c_row[32*j +: 32] = C[i][j]`（第 i 行，int32 二进制补码拼接）。

## 2. 端口

| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `clk` | in | 1 | 时钟，posedge |
| `rst` | in | 1 | 同步高有效复位 |
| `in_valid` | in | 1 | 输入拍有效 |
| `in_ready` | out | 1 | 可接收输入拍 |
| `a_row` | in | 32 | A 矩阵一行（见打包格式） |
| `b_row` | in | 32 | B 矩阵一行（见打包格式） |
| `out_valid` | out | 1 | 输出拍有效 |
| `out_ready` | in | 1 | 下游就绪 |
| `c_row` | out | 128 | C 矩阵一行（见打包格式） |

复位状态：`in_ready=1, out_valid=0`；`c_row` 复位期间任意。

## 3. 时序与协议

- 一次乘法由 **4 个输入拍**（行 0,1,2,3，顺序固定）与 **4 个输出拍**（行 0,1,2,3，顺序固定）组成。
- 输入拍之间允许任意间隔（`in_valid` 可为气泡）；`in_ready` 拉低期间输入方保持数据。
- 最后一个输入拍被接受后，**≤ 32 拍**内 `out_valid` 必须拉起；输出拍在 `out_valid && out_ready` 的时钟沿被消费，未被消费期间 `c_row` 与 `out_valid` 必须保持稳定。
- **不要求**在输出排空期间接受下一组输入（`in_ready` 可拉低），但输出完成后必须能开始下一组。
- 输出数据只要求功能正确，实现架构不限（脉动/并行/迭代均可）——PPA 由综合结果体现。

## 4. 性能要求

- 背靠背 8 组矩阵（组间输入 0 气泡，若 `in_ready` 允许）：全部结果正确；
- 记录并报告：末输入拍→首输出拍延迟、总事务拍数（不作硬性约束，超出 32 拍延迟判功能失败）。

## 5. 测试点（权重均等）

| 测试 | 内容 |
|---|---|
| `test_identity` | A=I, B=I → C=I；协议时序教学性校验 |
| `test_known` | 固定小数值矩阵，结果已知 |
| `test_random` | 20 组随机矩阵（全 int8 范围含 ±128），逐元素比对 |
| `test_extremes` | 全 -128、全 127、混合极值 |
| `test_backpressure` | 输出侧随机背压，结果完整性 |
| `test_backtoback` | 8 组连续提交，比对结果与组序 |
