# CASE: uart — UART 收发器 (8N1)

- 顶层模块名：`uart_trx`
- 难度：★★☆☆
- 考察点：FSM、波特率发生、过采样、位级时序一致性

## 1. 功能要求

全双工 UART：一个发送器 + 一个接收器，8 数据位、无校验、1 停止位（8N1），LSB 先传。
线空闲电平为 1。帧格式：`起始位(0)` + `D0..D7` + `停止位(1)`。

波特率由运行时输入 `div` 决定：**1 个过采样 tick = `div` 个 clk 周期，1 个位时间 = 16 个 tick = `16*div` 个 clk**。`div` 合法范围 1..65535，测试中使用 2、3、7 等小值。`div` 只在空闲时改变，传输中保持稳定。

## 2. 端口

| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `clk` | in | 1 | 时钟，posedge |
| `rst` | in | 1 | 同步高有效复位 |
| `div` | in | 16 | 分频系数（见上） |
| `tx_data` | in | 8 | 待发送字节 |
| `tx_valid` | in | 1 | 发送请求 |
| `tx_ready` | out | 1 | 发送器可接受新字节 |
| `txd` | out | 1 | 串行发送线 |
| `tx_busy` | out | 1 | 发送进行中（含停止位） |
| `rxd` | in | 1 | 串行接收线 |
| `rx_data` | out | 8 | 接收字节 |
| `rx_valid` | out | 1 | 单周期脉冲：收到完整字节（若同时 rx_err=1 则数据无效） |
| `rx_err` | out | 1 | 与 `rx_valid` 同拍：帧错误（停止位采样为 0） |

复位状态：`txd=1, tx_ready=1, tx_busy=0, rx_valid=0, rx_err=0, rx_data` 任意。

## 3. 时序与协议

### 发送

- `tx_valid && tx_ready` 的时钟沿锁存字节并立即开始发送（首 tick 计数从下一拍开始，允许 1~2 拍内拉低 `txd`，但每位宽度必须为精确 `16*div` 个 clk，误差 0）。
- 发送期间 `tx_ready=0`；停止位发完后回到空闲。允许在停止位最后 `div` 个 tick 期间提前拉高 `tx_ready`（实现自由），但只要 `tx_valid && tx_ready` 成立就必须正确排队/发送下一字节。**禁止丢字节**。
- `tx_busy` 从字节被接受到停止位结束为 1。

### 接收

- 空闲时监测 `rxd` 下降沿；检测到后等待 8 tick（半位时间）确认 `rxd` 仍为 0（否则为假起始，回空闲，**不得**产生 `rx_valid`）。
- 之后每个数据位在位中点采样：在第 7、8、9 tick（以位起始为 0）采样三次做**多数表决**。
- 停止位（第 9 位）中点采样为 0 → `rx_err=1` 与 `rx_valid` 同拍输出；为 1 → `rx_err=0`。
- 收到停止位中点后即可回空闲；必须能正确接收**背靠背**字节（停止位结束后立即跟新起始位）。
- 采样容差：测试激励的位边沿与理想位置的偏差 ≤ 1 个 clk（在 `div≥2` 时不得出错）。

## 4. 性能要求

- 背靠背接收 64 字节（间隔 0~2 clk 随机）不得丢字节；
- 发送 16 字节连发，波形逐位校验。

## 5. 测试点（权重均等）

| 测试 | 内容 |
|---|---|
| `test_tx_single` | 发送 0xA5，按 div 逐 tick 校验 txd 波形与 tx_busy |
| `test_tx_backtoback` | 16 个随机字节连发，波形解码比对 |
| `test_rx_single` | 理想波形驱动 rxd，校验 rx_data/rx_valid/rx_err |
| `test_rx_stream` | 48 个随机字节背靠背（含随机位间隙），逐字节比对 |
| `test_rx_framing_err` | 停止位拉低 → rx_err=1；随后恢复正常 |
| `test_rx_false_start` | 毛刺（短于半位的低脉冲）不得产生 rx_valid |
| `test_loopback` | txd 直连 rxd，64 随机字节 + 中途改 div |
| `test_reset_during_rx` | 接收中途复位，恢复后可正常接收 |
